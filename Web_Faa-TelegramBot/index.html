🚀 Install

  1. Install Node.js 20+, Python 3.10+, FFmpeg (lihat requirement.md).
  2. Ambil token dari @BotFather (/newbot).
  3. Jalankan: 
    cd Faa-Telegram-Bot_win
npm install
py -3 -m pip install -U yt-dlp rembg
set BOT_TOKEN=tempel_token_disini && npm start
  4. Setup pertama minta Telegram user ID owner (lihat via @userinfobot).
  5. Tes: /ping lalu /menu.

❓ FAQ

Butuh QR / pairing seperti bot WA?

Tidak. Bot Telegram pakai token resmi @BotFather. Tidak ada ban companion, tidak ada Chrome.

Sticker dikirim ke mana?

Bot membuat sticker-set sendiri (faa_pack_by_...) otomatis. Kirim gambar + caption !s.

!tagall tidak menandai semua?

Limitasi Bot API: hanya member yang pernah chat yang tercatat. Itu yang ditandai.

409 Conflict?

Ada 2 bot jalan dengan token sama. Matikan salah satu.
